# SQLMonitoringPerfmon-273939

Kursrepository zum Inhouse-Kurs **SQL Server – Monitoring und Performance-Tuning** der ppedv AG. Es enthält SQL-Beispiele und Materialien zu Einrichtung, Administration und Performanceanalyse von SQL Server.

## Repository-Stammverzeichnis

- `MaintenanceSolution.sql`: SQL Server Maintenance Solution für Backups, Integritätsprüfungen sowie Index- und Statistikwartung.
- `Spieltabelle.sql`: SQL-Skript zum Erstellen beziehungsweise Befüllen einer Beispieltabelle.
- `FirstResponderKit.zip`: Archiv mit dem First Responder Kit.

## Modul01ServerSetup

Skripte zur Installation und Grundeinrichtung eines SQL Servers, einschließlich Virtualisierung und Konfiguration von MAXDOP.

## Modul02SystemDBs

Skript zur Einrichtung beziehungsweise Konfiguration der SQL-Server-Systemdatenbanken.

## Modul03DBSettings

Beispiele zu Datenbankdesign, DB-Einstellungen und Datenbankobjekten sowie zu Dateigruppen und Tabellenpartitionierung.

## Modul05BackupSnapshot

Skripte und Beispiele zu Datenbanksicherungen und Datenbank-Snapshots.

## Modul10Monitoring

Materialien zur Leistungsüberwachung und Diagnose: Wait-Statistiken, Query Store, Monitoring-Werkzeuge und Perfmon-Indikatoren. Enthält außerdem eine Perfmon-Vorlage sowie Diagnoseabfragen für SQL Server 2022.

## Modul11IndizesStatistiken

Skripte zur Analyse und Pflege von Indizes und Statistiken, darunter Beispiele für fehlende und überflüssige Indizes sowie Forward Records.

## Modul12Locks

Beispiele zu Sperren und zur Momentaufnahmeisolation in SQL Server.
